Bybit Pay signs each payment webhook so that the merchant can verify its source and integrity. This signature applies only to webhook notifications sent by Bybit Pay.

## Obtain the public key

Create a webhook RSA key in the Bybit Pay Merchant Portal and copy the public key shown there. Store the public key securely in your webhook service.

The private key is managed by Bybit Pay and is never returned to the merchant. If you delete and recreate the webhook RSA key, update the public key in your webhook service before processing notifications signed by the new key.

## Algorithm

| Item | Value |
|:-----|:------|
| Key type | RSA 2048-bit |
| Hash | SHA-256 |
| Padding | PKCS#1 v1.5 |
| Algorithm name | SHA256withRSA / RSASSA-PKCS1-v1_5_SHA_256 |
| Signature transport encoding | Base64 |

Base64 is used only to encode the binary signature for the HTTP header. It does not change the JSON body and is not an encryption algorithm.

## Signature content

The string to verify is:

~~~text
timestamp + raw_request_body
~~~

- timestamp is the exact value of the timestamp request header.
- raw_request_body is the exact JSON text received over HTTP.
- Do not parse, reformat, sort, escape, or reserialize the JSON before verification.
- Do not add a separator, newline, or whitespace between the two values.

For example:

~~~text
1736233260{"merchantId":"305142568","paymentType":"E_COMMERCE","status":"PAY_SUCCESS"}
~~~

## Verification steps

1. Read the timestamp and signature request headers.
2. Read and retain the raw HTTP request body.
3. Concatenate the timestamp and raw body without a separator.
4. Base64-decode the signature header.
5. Verify the decoded signature with SHA-256, PKCS#1 v1.5, and the RSA-2048 public key copied from the Merchant Portal.
6. Parse and process the JSON body only after verification succeeds.

### Java example

~~~java
import java.nio.charset.StandardCharsets;
import java.security.KeyFactory;
import java.security.Signature;
import java.security.spec.X509EncodedKeySpec;
import java.util.Base64;

static boolean verifyWebhook(
        String timestamp,
        byte[] rawRequestBody,
        String signatureBase64,
        String publicKeyPem
) throws Exception {
    String pemBody = publicKeyPem
            .replace("-----BEGIN PUBLIC KEY-----", "")
            .replace("-----END PUBLIC KEY-----", "")
            .replaceAll("\\s", "");

    var publicKey = KeyFactory.getInstance("RSA").generatePublic(
            new X509EncodedKeySpec(Base64.getDecoder().decode(pemBody)));

    Signature verifier = Signature.getInstance("SHA256withRSA");
    verifier.initVerify(publicKey);
    verifier.update(timestamp.getBytes(StandardCharsets.UTF_8));
    verifier.update(rawRequestBody);
    return verifier.verify(Base64.getDecoder().decode(signatureBase64));
}
~~~

Return an error and do not process the notification when verification fails.
